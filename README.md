# Портфолио Анастасии Еронен

Готовый статический сайт. Тексты, изображения, локальный шрифт, графики и анимации включены. Установка зависимостей не требуется.

## Адрес сайта

Для личного сайта создайте репозиторий **AnastasiaEron.github.io**. Адрес: **https://anastasiaeron.github.io/**. Домен `github.io` без имени пользователя не является адресом личного сайта.

## Загрузка

1. Распакуйте ZIP на компьютере.
2. Загрузите **содержимое** архива в корень репозитория: `index.html` должен лежать прямо в корне, а не во вложенной папке.
3. Сохраните папки `.github` и файлы `.nojekyll`, `.gitignore`, даже если файловый менеджер скрывает их.
4. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
5. После загрузки в ветку `main` дождитесь успешного выполнения задания во вкладке **Actions**.
6. Откройте https://anastasiaeron.github.io/ и проверьте страницы на телефоне.

Если удобнее без Actions: в Settings → Pages выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`. В архиве уже выставлены правильные canonical для личного сайта.

## Страницы

- `index.html` — главная
- `projects/polymer-supply/index.html` — модель поставок полимеров
- `projects/transport-forecast/index.html` — прогнозирование перевозок и интерактивные графики
- `research/index.html` — научные работы и фильтры
- `404.html` — страница ошибки

Все внутренние ссылки и ссылки на ресурсы относительные. Полные абсолютные адреса сохранены только в SEO-метаданных, robots.txt и sitemap.xml — это необходимо для правильного указания адреса сайта.

## Если репозиторий будет называться иначе

Сайт сможет работать по адресу `https://anastasiaeron.github.io/имя-репозитория/`: внутренние пути останутся рабочими. При публикации через Actions абсолютные canonical, Open Graph, robots.txt и sitemap.xml настроятся автоматически по адресу Pages.

Для ручной подготовки файлов с другим адресом:

```sh
python3 scripts/build.py --base-url https://anastasiaeron.github.io/portfolio
```

Загрузите содержимое полученной папки `_site` в репозиторий или публикуйте её через Actions. Не переносите внутрь этой папки исходные scripts и .github.

## Проверка на компьютере

Откройте `index.html` двойным щелчком. Скрипты не используют серверную часть или запросы к API. Для проверки через локальный HTTP-сервер, если установлен Python:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Перед публикацией проверьте главную, оба кейса, научные работы, увеличение изображений, переключение маршрута и фильтры графика.

## Редактирование

- Тексты — соответствующие `.html`
- Общие цвета и адаптивность — `assets/style.css`
- Графики — `assets/project.js`
- Фильтры и эффекты — `assets/ui.js`
- Изображения — `assets/portrait.jpg`, `assets/map.jpg`, `assets/forecast.jpg`

Файл `assets/manrope-license.txt` содержит лицензию шрифта. Его следует сохранить.
